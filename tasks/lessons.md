# lessons

ユーザーから修正を受けたら、1ミスにつき1ルールを追記する。

形式：
- Mistake: 何が間違っていたか
- Rule: 次回どうするか
- Check: 早期に検出する方法

## コマンド1つで済む作業
- Mistake: Claude の GitHub Actions 連携の認証方式を、コマンドを打つだけで済む作業なのに細かく質問した。
- Rule: 公式コマンド1つで済む作業は、手順の詳細を計画や Issue に書かず、コマンド名だけ示す。
- Check: 質問や Issue 本文を書く前に「これはユーザーがコマンドを打つだけで済むか」を確認する。

## 警告の出し方
- Mistake: 警告の表示方法を指定しないまま仕様化したため、モーダルで出る余地が残っていた（ユーザーから「ダイアログではなく下部かタブに」と指摘）。
- Rule: 警告・通知は操作を止めない場所（下パネル、インライン、アイコン）に出す。モーダルは、元に戻せない操作の確認にだけ使う。
- Check: 仕様書や実装で、警告系の文言が `Dialog`／`alert`／`confirm` を使っていないか検索する。
