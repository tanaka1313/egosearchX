# 画面仕様書：エゴサ支援Webアプリ（仮称 EgoSearch Studio）

関連文書：`docs/requirements.md`（要件定義書）。機能番号 F1〜F9 は要件定義書に対応する。
「要調査」は要件定義書8章の確認が終わるまで確定しない項目。

## 1. 画面一覧とルーティング

| ID | 画面 | パス | 主な利用者 | 対応要件 |
|---|---|---|---|---|
| S1 | クイック実行 | `/` | タレント本人、ファン | F6, F7 |
| S2 | スタジオ（IDE風） | `/studio` | マネージャー、開発者 | F2〜F6, F8 |
| S3 | ランチャー | `/launch#<データ>` | 全員（ブックマーク経由） | F7 |
| S4 | 設定 | `/settings` | 全員 | F2, F9 |
| M1 | メンバー選択ダイアログ | （S1/S2から開く） | 全員 | F1, F6 |
| M2 | URL取り込みダイアログ | （S2から開く） | 上級者 | F4 |
| M3 | 検索セット発行ダイアログ | （S1/S2から開く） | 全員 | F7 |

- 全画面共通のヘッダー：ロゴ、画面切替（クイック実行／スタジオ／設定）、ダーク/ライト切替。
- サーバー側の処理は無く、全画面をクライアントで描画する。`/launch` はハッシュ部分をサーバーに送らない点を利用する。

## 2. 共通コンポーネント

| 名前 | 内容 |
|---|---|
| PresetCard | プリセット名、タグ、使用エンジン（X/Yahoo）のバッジ、最終実行日時、実行ボタン |
| EngineBadge | 「X」「Yahoo」の表示。Yahooで使えない演算子があるときは警告アイコンを付ける |
| QueryPreview | 生成した検索文字列を等幅フォントで表示。コピーボタン付き |
| UrlPreview | エンジンごとの生成URL。コピーと「開く」ボタン付き |
| WarningList | 警告の一覧（例：「list: はYahooでは使えません」）。黙って削除した項目が無いことを示す。**ダイアログ・トーストでは出さず**、下パネル／プレビュー内／アイコンのホバー表示に出す |
| ConfirmDialog | 削除など元に戻せない操作の確認 |
| Toast | 保存・コピー・エラーのフィードバック。エラーは必ず表示する |

## 3. S1：クイック実行（`/`）

目的：専門知識がなくても、ワンクリックで毎日のエゴサを実行する。

### レイアウト
```
┌────────────────────────────────────────────┐
│ ヘッダー                                   │
├────────────────────────────────────────────┤
│ 検索セット：[毎朝のエゴサ ▼]  [＋新規]     │
│                                            │
│ ┌ PresetCard ┐ ┌ PresetCard ┐ ┌ PresetCard ┐│
│ │名前エゴサ  │ │公式タグ    │ │箱リプライ  ││
│ │X  最終 昨日│ │X           │ │X           ││
│ │ [実行]     │ │ [実行]     │ │ [実行]     ││
│ └────────────┘ └────────────┘ └────────────┘│
│                                            │
│ [▶ すべて開く（N個のタブ）]  [ブックマーク用URLを発行] │
└────────────────────────────────────────────┘
```

### 要素と動作
- **検索セット選択**：保存済みの検索セットを選ぶ。0件のときは空状態（4.1）を表示する。
- **PresetCard の［実行］**：そのプリセットのURLを新しいタブで開き、最終実行日時を更新する。
- **［すべて開く］**：クリックを起点に `window.open` で全タブを開く。ブロックされた場合は S3 と同じ案内（6.3）を表示する。
- **［ブックマーク用URLを発行］**：M3 を開く。
- **［＋新規］**：M1 を開き、メンバー選択からテンプレート生成する（F6）。
- 各カードの［編集］は S2 の該当プリセットを開く。
- 日付の相対指定は、実行した時点の日時で計算する。

### 状態
| 状態 | 表示 |
|---|---|
| 初回（データなし） | 「メンバーを選んで検索を作りましょう」とM1への導線 |
| 通常 | カード一覧 |
| 警告あり | カードにEngineBadgeの警告アイコン。ホバーで内容を表示 |

## 4. S2：スタジオ（`/studio`）

目的：複雑なクエリを部分的に編集し、プリセットと検索セットを管理する（F2〜F6, F8）。

### 4.0 レイアウト（デスクトップ）
```
┌──────────────────────────────────────────────────────┐
│ ヘッダー                                             │
├───────────┬───────────────────────────┬──────────────┤
│ 左        │ 中央                      │ 右           │
│ エクスプロ│ [タブ1][タブ2][＋]        │ プレビュー   │
│ ーラー    │ ┌ クエリエディタ ───────┐ │  クエリ      │
│  事務所   │ │ GUI ツリー / 生テキスト │ │  X URL      │
│  └箱      │ │ （切替）               │ │  Yahoo URL  │
│   └メンバー│ └───────────────────────┘ │ ─────────── │
│  プリセット│                           │ URL解析      │
│  検索セット│                           │              │
├───────────┴───────────────────────────┴──────────────┤
│ 下パネル：警告 / ログ                                 │
└──────────────────────────────────────────────────────┘
```
- 各ペイン境界はドラッグでリサイズできる。各ペインは表示・非表示を切り替えられる。
- ペインの幅、表示状態、開いているタブはlocalStorageに保存する（F9）。
- スマホ（幅 768px 未満）では1カラムにし、下部のタブバーで「エクスプローラー／エディタ／プレビュー」を切り替える。下パネルはプレビュー内に統合する。

### 4.1 左：エクスプローラー
- ツリーは3つのセクションを持つ。
  1. **マスタ（閲覧のみ）**：事務所 → 箱/期 → メンバー。メンバーの右クリック／［…］メニューに「このメンバーで検索を作る」（M1と同じテンプレート生成）。卒業フラグのあるメンバーは薄く表示する。
  2. **プリセット**：クリックで中央にタブとして開く。［…］メニューに複製、削除、名前変更、検索セットへ追加。ドラッグで並べ替え。
  3. **検索セット**：セットを展開するとプリセットが並ぶ。［▶］で一括実行、［発行］でM3を開く。
- 上部に絞り込み入力欄（名前・タグで絞り込み）。
- マスタを編集する操作は表示しない（ユーザーは閲覧のみ）。

### 4.2 中央：クエリエディタ
タブごとに1つのプリセットを編集する。タブには未保存の印（●）を付ける。

**ヘッダー行**：プリセット名、タグ、使用エンジン（X／Yahoo／両方）、［保存］、［複製］。

**表示切替**：［GUI］／［テキスト］。両者は双方向に同期する（F3）。

#### GUI ツリー表示
- ノードの種類：語（完全一致／通常／表記ゆれ展開）、除外、アカウント条件、フィルタ、期間、グループ（AND／OR）、生トークン。
- 各ノードの操作：ON/OFF、削除、並べ替え（ドラッグ）、別グループへの移動、複製。
- グループは入れ子にでき、折りたたみ可能。`(A OR B) AND C` は「ANDグループの中に、ORグループ（A, B）とC」として表示する。
- ［＋］ボタンでノードを追加する。追加できる種類は一覧から選ぶ。
- 生トークンは灰色で表示し、編集は文字列のまま行える。削除しない限りURLに出力される。

#### 共通設定との関係
- ツリーの上に「共通設定から継承」のセクションを表示する。共通の完全一致・あいまい・除外が項目ごとにチェックボックスで並び、チェックを外すとその検索でだけ無効になる。
- 共通設定そのものの編集は S4 で行う。ここからは［共通設定を編集］リンクで移動する。

#### 期間（日付の自動入力）
- 選択肢：指定なし／今日／昨日から／N日前から／前回実行時から／日付を直接指定。
- 「前回実行時から」は、最終実行日時が無い初回は「指定なし」として扱い、その旨を表示する。
- 期間はX検索にのみ適用される。Yahooにも出力するエンジン設定のときは、プレビューの警告欄に「Yahooでは期間指定が使えません」と表示する（ダイアログは出さない）。
- `until:` は指定日を含まない（UTC基準）。画面では「終了日を含む」と表示し、出力時に翌日へ変換する。生成結果の `until:` の日付をプレビューに並べて表示する。

#### テキスト表示
- 生のクエリ文字列を編集する。構文エラーは該当箇所に下線とメッセージを表示し、GUIには反映しない（最後に有効だった状態を保つ）。

### 4.3 右：プレビュー
- **QueryPreview**：Xとして出力される検索文字列、Yahooとして出力される検索文字列。
- **UrlPreview**：エンジンごとのURL（［コピー］［開く］）。
- **WarningList**：Yahooで使えない演算子、URLが長すぎる場合の警告。プレビュー内に常時表示し、操作は止めない。
- 編集のたびに即時更新する。
- **URL解析**：［URLを貼り付けて取り込む］ボタンで M2 を開く。

### 4.4 下パネル
- タブ：「警告」「ログ」。ログには実行したURL、取り込み結果、保存の成否を残す（セッション内のみ）。
- 閉じた状態を既定とし、警告が出たときに件数をバッジで示す。**警告の出力先はこのパネルを基本とし、勝手に開いたりフォーカスを奪ったりしない**。
- 警告は、Yahoo変換で除外・変換した項目と理由を1行ずつ表示する。クリックで該当ノードに移動する。

## 5. S4：設定（`/settings`）

| セクション | 内容 |
|---|---|
| 共通設定 | 全検索に共通の完全一致・あいまい（通常／表記ゆれ展開）・除外を、それぞれ複数追加・並べ替え・削除する。各項目にON/OFFを持つ |
| 表示 | ダーク/ライト、スタジオのペイン配置を初期化 |
| データ | 保存済みデータの件数表示、全データ削除（ConfirmDialog必須）。**エクスポート/インポートはMVP対象外** |
| 注意書き | 「データはこのブラウザにだけ保存されます。ブラウザのデータを消すと失われます。ブックマーク用URLが控えになります」 |

## 6. S3：ランチャー（`/launch#<データ>`）

### 6.1 目的
ブックマークから開いたとき、設定入りの検索セットを一括で実行する（F7）。

### 6.2 レイアウトと動作
```
┌────────────────────────────────┐
│ 検索セット名：毎朝のエゴサ      │
│ 5件の検索を新しいタブで開きます │
│                                │
│   [▶ すべて開く]               │
│                                │
│ 1. 名前エゴサ（X）      [開く] │
│ 2. 名前エゴサ（Yahoo）  [開く] │
│ ...                            │
│ [スタジオで編集]               │
└────────────────────────────────┘
```
- ページを開いただけでは自動でタブを開かない。ブラウザのポップアップ制限を避けるため、**［すべて開く］のクリックを起点にする**。
- 日付の相対指定は、このページを開いた時点の日時（［すべて開く］の押下時点）で計算する。
- 個別の［開く］は、一括で開けなかったときの代替手段として常に表示する。
- ［スタジオで編集］は、取り込んだ内容を新規のプリセット／検索セットとして保存するか確認してから S2 に移動する。勝手に上書き保存しない。

### 6.3 ポップアップがブロックされた場合
- 開けたタブ数と失敗数を表示する。
- 「ブラウザのポップアップを許可してから、もう一度［すべて開く］を押してください」と案内する。
- 個別リンク一覧から手動で開けるようにする。

### 6.4 エラー状態
| 状態 | 表示 |
|---|---|
| ハッシュが無い／壊れている | 「ブックマークURLを読み込めませんでした」とクイック実行への導線 |
| 未知のバージョン | 「新しい形式のURLです。アプリを更新してください」 |
| データが大きく、URLが長い | 発行時（M3）に警告済み。読み込めた場合は通常どおり |

## 7. ダイアログ

### M1：メンバー選択（F1, F6）
- 左に事務所 → 箱/期のツリー、右にメンバー一覧（検索欄付き、複数選択可）。
- 下部で生成するテンプレートをチェックで選ぶ：名前エゴサ／公式タグ／同じ箱からのリプライ／Yahoo版の名前エゴサ。
- 箱のリストIDが未設定の箱では、「同じ箱からのリプライ」を無効にし、理由を表示する。
- ［作成］で、選択した組み合わせのプリセットを生成する。保存先の検索セット（既存／新規）も選ぶ。

### M2：URL取り込み（F4）
- テキスト入力欄にXまたはYahooのURLを貼り付ける。
- 解析結果を、ツリー形式で即時プレビューする。解析できなかった部分は「生トークン」として表示する。
- 対応外のURL（`x.com/search` でも `q` が無い等）には、理由を表示する。
- ［取り込む］で新規プリセットとしてエディタに開く。既存プリセットは上書きしない。

### M3：検索セット発行（F7）
- 検索セット名、含めるプリセットの一覧を表示する。
- 生成されたURLを表示し、［コピー］と「ブックマークに追加する手順」の案内を出す。
- URLの長さが警告水準を超えたときは、含めるプリセットを減らすよう促す（上限値は要調査）。

## 8. アクセシビリティ・表示方針
- すべての操作をキーボードで行えるようにする（ツリーは矢印キー、ダイアログはEscで閉じる）。
- 色だけで状態を示さない（警告はアイコンと文言も併用）。
- UIの文言は日本語。クエリ文字列は等幅フォントで表示する。
- 最小対応幅は 360px。

## 9. 画面遷移
- S1 ⇄ S2 ⇄ S4：ヘッダーで相互に移動する。
- S1／S2 → M1／M2／M3：ダイアログで開く。
- ブックマーク → S3 →（［スタジオで編集］）→ S2。
