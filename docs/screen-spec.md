# 画面仕様書：エゴサ支援Webアプリ（仮称 EgoSearch Studio）

関連文書：`docs/requirements.md`（要件定義書）。機能番号 F1〜F12 は要件定義書（2026-11-17 改訂）に対応する。旧番号は要件定義書の付録Bを参照。
「要調査」は要件定義書8章の確認が終わるまで確定しない項目。
画面イメージは `/mock/mock6`（破棄予定のモック）で確認できる。**スマホを基準に設計し、PC は6.2で定める。**

## 2. 共通要素

### 2.1 ヘッダー
- 左に［≡］（メニューを開く）、次にアプリ名、右に［🔍］（コマンドパレット、Ctrl/⌘+K）。
- ヘッダーは画面上部に通常配置する。他の要素の下に潜らない。
- 1280px 以上は左メニューが常時表示のため［≡］を出さない。

### 2.2 左メニュー
- ［≡］で開く。**画面幅の約70%**（PC は最大 360px）。残りの約30%は半透明の幕で、**押すと閉じる**。全画面は覆わない。
- ヘッダーや他の要素と重ならない（メニューが最前面）。
- 上に閉じるボタン［×］。項目は**縦に並べる**：ホーム／条件ボタン／お気に入り／エゴサグループ／履歴／削除済み（件数バッジ）／URL取り込み／設定。現在のページには印と文言（「表示中」）を付ける。
- 項目を押すとそのページへ移動して閉じる。Esc で閉じ、フォーカスを［≡］に戻す。開いたときは［×］にフォーカスする。

### 2.3 コンポーネント
| 名前 | 内容 |
|---|---|
| ChipButton（条件ボタン） | ラベル、ON/OFF の印（✓）、小さな［×］（削除）、ドラッグの取っ手。「新」バッジ。リスト条件にはリストの印 |
| FavoriteRow | 名前、クエリ（等幅、1行省略）、エンジンのバッジ、［▶ 実行］［編集］［×］。参照先が削除済みなら警告アイコン |
| GroupButton | グループ名、件数、［▶］、「✓ 今日は済」／「今日は未」 |
| QueryPreview | 生成した検索文字列を等幅フォントで表示。コピーボタン付き。警告アイコン |
| EngineBadge | 「X」「Yahoo」。Yahooで使えない演算子があるときは警告アイコンを付ける |
| WarningList | 警告の一覧。**ダイアログ・トーストでは出さず**、クエリ表示の横の警告アイコン（押すと下に展開）／プレビュー内／アイコンのホバー表示に出す。パネルを勝手に開かず、フォーカスを奪わない |
| ConfirmDialog | 元に戻せない操作（完全削除、全データ削除）の確認 |
| Toast | 保存・コピー・エラー、および削除（［元に戻す］付き）のフィードバック。エラーは必ず表示する |
| CommandPalette | Ctrl/⌘+K。お気に入り・グループの実行とページ移動。Enter で実行、Esc で閉じる |

## 3. S1：ホーム（`/`）

目的：日課のエゴサをワンタップで実行し、直感操作で検索を組み立て、その延長で保存する。複雑な設定は持たない。

### 3.1 レイアウト（スマホ）
```
┌────────────────────────────────┐
│ [≡] EgoSearch            [🔍]  │
├────────────────────────────────┤
│ いつものエゴサ                  │
│ [▶今日のエゴサ(5) ✓今日は済]    │
│ [▶配信後エゴサ(3) 今日は未] [＋]│
├────────────────────────────────┤
│ ( 検索語を入力 …………… ) [完全一致]│
│ [✓RTを除く ×][ホロメンから ×]   │
│ [✓ネタバレ除外 ×][画像つき ×]   │
│ [返信のみ ×][昨日から ×] …      │
│ [もっと開く（+6）]    [＋ボタン] │
│ 期間 (なし)(今日)(昨日から)(前回から)(日付) │
│ クエリ（X）：ぺこら -filter:retweets list:…  ⚠1 │
│ [X で開く] [Yahoo で開く] [☆保存]│
│ ▸ 詳細設定（この検索だけ）       │
├────────────────────────────────┤
│ お気に入り                      │
│  名前エゴサ  ぺこら …  [▶][編集][×]│
│ 最近の履歴                      │
│  昨日 22:30 ぺこら … [再実行]   │
│  すべて見る →                   │
└────────────────────────────────┘
```

### 3.2 要素と動作
- **いつものエゴサ（エゴサグループ）**：最上段。グループのボタンを押すと、クリックを起点に `window.open` で全タブを開き、履歴に記録する。ブロックされたときは S9 と同じ案内を、ボタンの下に表示する（モーダルにしない）。［＋］でグループを作る（S4 の作成と同じ）。0件のときは「配信後などのまとめ実行を作れます」と［＋］を出す。
- **検索語**：入力すると、下のクエリ表示がすぐ更新される。［完全一致］で引用符の有無を切り替える。
- **条件ボタン**：タップで ON/OFF。各ボタンの横の小さな［×］で削除（削除済みへ移動。トーストに［元に戻す］）。ドラッグで並べ替える（キーボードは、フォーカスして Space で持ち上げ、矢印で移動、Space で確定）。ラベルを長押し（またはメニューの［編集］）すると M1 が開く。
  - **折りたたみ**：初期は2行目までを表示する。3行以上になるときは［もっと開く（+N）］を出し、押すと全件を表示する（開いたら［閉じる］）。隠れているボタンにはフォーカスが当たらない。
  - ［＋ボタン］で M1 を新規作成モードで開く（ラベルと中身、またはリストのURL/ID）。上限（30件）では無効にして理由を表示する。
- **期間**：指定なし／今日／昨日から／前回から／日付を直接指定。「前回から」は履歴が無い初回は「指定なし」扱いで、その旨を表示する。
- **クエリ表示**：X として出力される検索文字列。［コピー］。警告があるときは件数つきの⚠アイコン。押すと下に警告を展開する（Yahoo で使えない演算子など）。
- **［X で開く］［Yahoo で開く］**：新しいタブで開き、履歴に記録する。詳細設定で使った条件は、同じ中身のボタンが無ければ条件ボタンに自動追加し（「新」バッジ）、トーストではなくボタン列の「新」バッジで知らせる。
- **［☆ 保存］**：保存シート（M1 と同じ種類の下からのシート）を開く。名前を入れて「お気に入りに保存」。同じシートで「グループに追加：既存を選ぶ／新規作成」もできる。
- **詳細設定**：開閉エリア。**初期は閉じている**。開くと 3.3 の内容。
- **お気に入り**：FavoriteRow の一覧（上位数件）と［すべて見る → S3］。
- **最近の履歴**：直近3件と［すべて見る → S5］。［再実行］で同じ検索を開く。

### 3.3 詳細設定（個別設定、開閉エリア）
その検索だけの条件。可能な限り細かく指定できる。内容は要件定義書 F3 のとおり。

- セクション（それぞれ折りたたみ可）：語／アカウント／フィルタ／期間／エンジンと表示／条件ボタンの項目別の無効化。
  - **語**：完全一致・通常・表記ゆれ展開（複数の語をORで結ぶ）・除外を、それぞれ複数追加できる。
  - **アカウント**：from／to／メンション／list と、それぞれの除外。
  - **フィルタ**：リプライ、RT、引用、画像、動画、リンク、認証済み、言語、`min_faves`／`min_retweets`／`min_replies`。それぞれ「指定なし／含む／除く」の3択。
  - **期間**：N日前から、日付の直接指定などの細かい指定。「終了日を含む」と表示し、出力時に翌日へ変換する。
  - **エンジンと表示**：X／Yahoo／両方、Xの「最新」タブ。
  - **共通の無効化**：ONの条件ボタンの中身を項目ごとにチェックボックスで並べ、外すとこの検索でだけ無効になる。
- **高度な編集**（タブ）：［構造］と［テキスト］を切り替える。構造は木構造（ノードのON/OFF、削除、並べ替え、グループのAND/OR、生トークン）。テキストは生のクエリ文字列。双方向に同期し、構文エラーは該当箇所に表示して最後に有効だった状態を保つ。
- 設定は即時にクエリ表示とプレビューへ反映する。
- 「この検索をリセット」で個別設定を全部消す（元に戻せるので確認は出さず、トーストに［元に戻す］）。

### 3.4 状態
| 状態 | 表示 |
|---|---|
| 初回（データなし） | 条件ボタンに既定リスト（ホロライブ・にじさんじ）が入っている。お気に入り・履歴は空状態の案内 |
| 条件ボタンが上限 | ［＋ボタン］を無効にし、「上限です」と理由を表示。自動追加は止まる（履歴に「上限のため追加しませんでした」と残す） |
| 参照先が削除済み | 該当のお気に入り・グループにアイコンと「復元」への導線 |
| 警告あり | クエリ表示の⚠アイコン |

## 4. メニューのページ（S2〜S8）

共通：ヘッダーに「ホームへ戻る」のパンくずを置く。一覧は空状態（案内と次の操作）を持つ。削除は削除済みへ移し、トーストに［元に戻す］。

### S2：条件ボタン（`/buttons`）
- 一覧（ドラッグで並べ替え、キーボードでも移動可）。各行：ラベル、中身の要約（等幅）、ON/OFFの初期状態、［編集］［×］。現在の件数／上限（例：12/30）を表示する。
- **［＋ 追加］**：M1 を開く。ボタンの作り方は2つ：①ラベルと中身を入力、②**リスト**：URL（`https://x.com/i/lists/<ID>`）またはIDを貼る。ID を取り出して確認を表示する（例：「リスト 1412278227767218179」）。数字以外は受け付けない。
- 既定リスト（F1）から作られたボタンには「既定」の印を付ける。編集・削除はできる。削除後に既定へ戻したいときは「削除済み」から復元するか、［既定のボタンを追加］で再登録する。
- ホームと同じ折りたたみ（2行）は使わず、全件を一覧する。

#### M1：条件ボタンの編集（下からのシート。PC は右側のシート）
- **ラベル**：表示名（必須。20文字まで）。
- **中身**：条件の一覧。1つのボタンに複数の条件を持てる（例：ネタバレ除外 → 語A、語B）。各条件は種類（語・除外・完全一致・アカウント・リスト・フィルタ・生）と値。［＋条件を追加］、各条件の［×］、ドラッグで並べ替え。
- **プレビュー**：中身から生成される文字列（等幅）と、Yahoo で使えない演算子の警告。
- ［保存］／［キャンセル］。参照しているお気に入りの件数を表示し（「3件のお気に入りに反映されます」）、保存すると全部に反映する。
- 空のラベル・空の中身は保存できず、理由をフィールドの下に表示する（モーダルにしない）。

### S3：お気に入り（`/favorites`）
- 一覧（ドラッグで並べ替え）。各行：名前、クエリ、エンジン、最終実行、［▶ 実行］［編集］［複製］［×］。絞り込み入力欄。
- ［編集］：名前、検索語、使う条件ボタン、個別設定（S1 の詳細設定と同じ内容）、期間、エンジンを直す。保存先は同じお気に入り（上書きは、ユーザーが明示的に［保存］を押したときだけ）。
- 参照先が削除済みの条件ボタンを使っているものは、⚠アイコンと「条件ボタン『…』が削除済みです［復元］」。

### S4：エゴサグループ（`/groups`）
- 一覧。各グループ：名前、含むお気に入り（並べ替え可）、［▶ 一括実行］、［ブックマークURLを発行（M2）］、［編集］、［×］。「今日は済／未」。
- **作成**：［＋ 新しいグループ］で名前を入れ、お気に入りをチェックで選ぶ。既存のお気に入りだけでなく、現在のホームの検索から作ることもできる（S1 の保存シート）。
- 一括実行：クリック起点で全タブを開く。ブロック時は、開けた数／失敗数と、個別リンク一覧を表示する。
- 例：「配信後エゴサ（3個）」＝配信タグ、ファンアートタグ、切り抜きタグ。「今日のエゴサ」＝期間「前回から」を使う。

### S5：履歴（`/history`）
- 新しい順の一覧。各行：日時、検索語、使った条件ボタン、エンジン、実行元。［再実行］［☆ お気に入りに保存］［条件ボタンにする］。
- 件数（例：42/100）、［全件削除］（ConfirmDialog）。
- 自動追加で追加したボタン、上限のため追加しなかった条件を、履歴の行に印で示す。

### S6：削除済み（`/trash`）
- 条件ボタン・お気に入り・グループを、削除した新しい順に混在して表示する。種類のバッジ、名前、削除日時、［復元］［完全に削除］。件数（例：7/20）。
- 上限（20件）を超えると、古いものから自動で完全削除される。その旨を上部に常時表示する（「20件を超えると古いものから完全に削除されます」）。
- ［完全に削除］と［すべて完全削除］は ConfirmDialog（M3）を挟む。復元は確認なし。
- 復元先が上限に達している場合は、［復元］を無効にして理由を表示する。

### S7：URL取り込み（`/import`）
- テキスト入力欄にXまたはYahooのURLを貼り付ける。
- 解析結果を、ツリー形式で即時プレビューする。解析できなかった部分は「生トークン」として表示する。
- 対応外のURL（`x.com/search` でも `q` が無い等）には、理由を入力欄の下に表示する。
- ［ホームに読み込む］（検索語と個別設定に展開）／［新規お気に入りとして保存］。既存のデータは上書きしない。

### S8：設定（`/settings`）
| セクション | 内容 |
|---|---|
| 条件ボタン | 自動追加のON/OFF（既定ON）、［既定のボタンを追加］ |
| 履歴 | 履歴の記録のON/OFF、全件削除 |
| 表示 | ダーク/ライト |
| データ | 保存済みデータの件数表示、全データ削除（ConfirmDialog 必須）。**エクスポート/インポートはMVP対象外** |
| 上限（参考表示） | 条件ボタン30、削除済み20、履歴100（変更はコードの定数。画面からは変えない） |
| 注意書き | 「データはこのブラウザにだけ保存されます。ブラウザのデータを消すと失われます。ブックマーク用URLが控えになります」 |

## 5. S9：ランチャー（`/launch#<データ>`）

### 5.1 目的
ブックマークから開いたとき、設定入りのエゴサグループを一括で実行する（F8）。

### 5.2 レイアウトと動作
```
┌────────────────────────────────┐
│ グループ名：配信後エゴサ         │
│ 3件の検索を新しいタブで開きます   │
│                                │
│   [▶ すべて開く]               │
│                                │
│ 1. 配信タグ（X）        [開く] │
│ 2. ファンアート（X）    [開く] │
│ 3. 切り抜き（X）        [開く] │
│ [ホームで開く（新規として保存）] │
└────────────────────────────────┘
```
- ページを開いただけでは自動でタブを開かない。**［すべて開く］のクリックを起点にする**。
- 日付の相対指定は、［すべて開く］の押下時点の日時で計算する。
- 個別の［開く］は、一括で開けなかったときの代替手段として常に表示する。
- ［ホームで開く］は、取り込んだ内容を新規のお気に入り／グループとして保存するか確認してから S1 へ移動する。勝手に上書き保存しない。

### 5.3 ポップアップがブロックされた場合
- 開けたタブ数と失敗数を表示する。
- 「ブラウザのポップアップを許可してから、もう一度［すべて開く］を押してください」と案内する。
- 個別リンク一覧から手動で開けるようにする。

### 5.4 エラー状態
| 状態 | 表示 |
|---|---|
| ハッシュが無い／壊れている | 「ブックマークURLを読み込めませんでした」とホームへの導線 |
| 未知のバージョン | 「新しい形式のURLです。アプリを更新してください」 |
| データが大きく、URLが長い | 発行時（M2）に警告済み。読み込めた場合は通常どおり |

## 6. ダイアログ

### M2：ブックマークURL発行（F8）
- グループ名、含むお気に入りの一覧を表示する。
- 生成されたURLを表示し、［コピー］と「ブックマークに追加する手順」の案内を出す。
- URLの長さが警告水準を超えたときは、含めるお気に入りを減らすよう促す（警告水準は定数。要件定義書 F8）。警告はダイアログ内のインライン表示で、別のモーダルは出さない。

### M3：確認ダイアログ
- 完全削除、すべて完全削除、履歴の全件削除、全データ削除だけに使う。［キャンセル］と赤の実行ボタン。Esc で閉じる。

### 6.1 モーダルにしないもの
警告、保存、削除（削除済みへの移動）は、モーダルを使わない。削除はトースト（［元に戻す］付き）、警告はアイコンとインライン表示。

### 6.2 PC（768px以上）の配置
スマホの配置を基準に、広い画面では次のようにする。
- **ホーム**：タイル型。左の大きいタイルに「検索の組み立て」（検索語、条件ボタン、期間、クエリ、［開く］）。右または下に小さいタイル：いつものエゴサ、お気に入り、最近の履歴。詳細設定は大タイルの下に開く。条件ボタンの折りたたみは、スマホと同じ2行。
- **左メニュー**：768px〜1279px はスマホと同じ開閉（最大 360px）。1280px 以上は常時表示のサイドバー。
- **メニューのページ**：一覧は2カラム（一覧＋編集シート）。M1 は右側のシート。
- **コマンドパレット**：中央に表示。幅は最大 480px。
- キーボードショートカット：Ctrl/⌘+K でパレット、Esc で閉じる。

## 7. アクセシビリティ・表示方針
- すべての操作をキーボードで行えるようにする（メニューは Tab／Esc、並べ替えは Space＋矢印、ダイアログは Esc で閉じる）。
- 色だけで状態を示さない（条件ボタンの ON は ✓ と `aria-pressed`、警告はアイコンと文言を併用）。
- UIの文言は日本語。クエリ文字列は等幅フォントで表示する。
- 最小対応幅は 360px。768px 未満は1カラム。
- 折りたたみで隠した要素は、フォーカスが当たらないようにする（`inert`）。
- 件数の上限値は画面の文言に直書きせず、定数から出す。

## 8. 画面遷移
- ホーム ⇄ 各メニューのページ：左メニュー（［≡］またはサイドバー）で移動する。コマンドパレットからも移動できる。
- ホーム → M1（条件ボタンの編集）／M2（発行）：シート・ダイアログで開く。
- ブックマーク → S9 →（［ホームで開く］）→ S1。
- 履歴／お気に入り → ［再実行／実行］→ 新しいタブ（画面は移動しない）。
