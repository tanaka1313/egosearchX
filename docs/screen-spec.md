関連文書：`docs/requirements.md`（要件定義書）。機能番号 F1〜F12 は要件定義書（2026-11-17 改訂）に対応する。旧番号は要件定義書の付録Bを参照。
「要調査」は要件定義書8章の確認が終わるまで確定しない項目。
画面イメージは `/mock/mock6`（破棄予定のモック）で確認できる。**スマホを基準に設計し、PC は6.2で定める。**

## 2. 共通要素

### 2.1 ヘッダー
- 左から順に、［≡］（メニューを開く）、アプリ名、**機能タイトル**（「X（Twitter）」。今後 YouTube 検索・TikTok 検索の同様のツールを同じサイトに足す予定なので、どの機能の画面かを示す。予定のみで Issue は作らない）。コマンドパレットのボタンは置かない（Ctrl/⌘+K とメニューの項目から開く）。
- **「いつものエゴサ」の帯**：ヘッダーのすぐ下に、**どのページでも（ランチャー S9 を含む）**固定で置く。いつものエゴサの先頭2件を並べる。帯の高さはいつものエゴサが0件でも同じ。「いつものエゴサ」の文字の横に**［＋］**（追加。S4 の追加シートを開く）を置く。
- いつものエゴサのボタンは `▶ 配信後エ…(3)` の形にする。名前は幅に収まらない分を「…」で省略し、件数は常に表示する。今日実行済みのものには✓を付ける（色だけで示さない。✓の枠は常に確保し、押しても幅が変わらない）。省略しない名前は `title` と `aria-label` に入れる。表示件数は定数 `LIMITS.headerGroups`（2）。
- 3件目以降を実行したいときは、いつものエゴサのページ（S4）から実行する。S4 へのリンク「一覧」は、幅に余裕があるとき（sm 以上）だけ出す。余裕が無いときは出さない（メニューから行ける）。
- いつものエゴサが0件のときは、ボタンの代わりに「まだありません」を出す（［＋］は常にある）。
- いつものエゴサを実行してタブをブロックされたときは、ヘッダーのすぐ下に1行のインライン表示（`role="status"`、モーダルにしない）で、開けた数と許可の手順を案内する。個別リンクは S4 の一覧にある。
- ヘッダーは画面上部に通常配置する。他の要素の下に潜らない。
- 1280px 以上は左メニューが常時表示のため［≡］を出さない。
- ランチャー（S9）でも「いつものエゴサ」の帯を出す（帯自体がランチャーの入口のため）。フッターだけ、画面に集中させるため出さない。

### 2.1.1 フッター
- 画面の下に固定し、**最後の履歴を1件だけ**表示する：「前回 昨日 22:30 ぺこら…　［再実行］［履歴 →］」。履歴が無いときは「実行するとここに残ります」。
- ［履歴 →］は履歴のページ（S5）へ移動する。履歴の一覧はホームに置かない。
- トーストはフッターの上に出す（重ならない）。本文の下には、フッターの高さぶんの余白を取る。

### 2.2 左メニュー
- ［≡］で開く。**画面幅の約70%**（PC は最大 360px）。残りの約30%は半透明の幕で、**押すと閉じる**。全画面は覆わない。
- ヘッダーや他の要素と重ならない（メニューが最前面）。
- 上に閉じるボタン［×］。項目は**縦に並べる**：ホーム／条件ボタンの編集／お気に入り／いつものエゴサ／履歴／削除済み（件数バッジ）／URL解析／設定／コマンドパレット。**メニューから、すべての機能と編集に行ける**ようにする。現在のページには印と文言（「表示中」）を付ける。
- 項目を押すとそのページへ移動して閉じる。Esc で閉じ、フォーカスを［≡］に戻す。開いたときは［×］にフォーカスする。

### 2.3 コンポーネント
| 名前 | 内容 |

| FavoriteRow | 名前、クエリ（等幅、1行省略）、エンジンのバッジ、［▶ 実行］。**ホームでは実行だけ**。編集・複製・削除は S3 で行う（S3 では［編集］［×］も出す）。参照先が削除済みなら警告アイコン |

## 3. S1：ホーム（`/`）

目的：検索語を入れ、条件ボタンを押し、開く。**直感操作だけで済む画面にする。** 日課の実行はヘッダー下の帯（全ページ）、前回の確認はフッターに任せ、ホームには検索の組み立てを置き、お気に入りは下に閉じた1行で置く（開閉は localStorage に記憶、初回は閉じる）。**表示と編集は分ける**：ホームの部品は押すだけで、追加・編集・削除・並べ替えはメニューの専用ページで行う。

### 3.1 レイアウト（スマホ。PC も同じ1カラムで、中央に寄せる）
```
┌────────────────────────────────┐
│ [≡] EgoSearch  [X（Twitter）]    │  ← ヘッダー（機能タイトル）
├────────────────────────────────┤
│ いつものエゴサ [＋] [▶配信後エ…(3)✓][▶今日…(5)] │  ← 帯（全ページ）
├────────────────────────────────┤
│ ( 検索語を入力 …………… ) [完全一致]│
│ [✓RTを除く][✓ホロメンから]       │  ← 押すだけ。ON は塗り＋✓、OFF は枠＋○
│ [○ネタバレ除外][○画像つき] …    │
│ [もっと開く（+6）]   ボタンを編集 →│  ← 2行目の末尾。編集は右端
│ 期間 (なし)(今日)(昨日から)(前回から)│  ← 日付・N日前からは詳細条件
│ ぺこら -filter:retweets list:… →⚠1│  ← 1行固定。長いときは横スクロール
│ [X で開く] [☆保存] [⋯]          │
│ ▸ 詳細条件                       │
│ ─────────────────────────────  │
│ ▸ ☆ お気に入り（4）              │  ← 閉じた1行（開閉は記憶）
├────────────────────────────────┤
│ 前回 昨日 22:30 ぺこら… [再実行] 履歴 →│  ← フッター（最後の履歴1件）
└────────────────────────────────┘
```

### 3.2 要素と動作
- **いつものエゴサ**：ホーム本体には置かず、**ヘッダー下の帯に固定**する（2.1。ランチャーを含む全ページ）。どのページからでも1タップで実行できる。押すと、クリックを起点に `window.open` で全タブを開き、履歴に記録する。
- **検索語**：入力すると、下のクエリ表示がすぐ更新される。［完全一致］で引用符の有無を切り替える（ON は塗り、OFF は枠）。
- **条件ボタン**：タップで ON/OFF を切り替えるだけ。見た目は 2.3 の ChipButton のとおり、**押しても幅・高さが変わらない**。
  - **折りたたみ**：初期は2行目までを表示する。3行以上になるときは、2行目の末尾に［もっと開く（+N）］を出し、押すと全件と**サジェスト検索条件**（最大20件、破線枠のボタン。押すとこの検索にだけ ON/OFF）を表示する。**開いた後の［閉じる］は置かない**。隠れているボタンにはフォーカスが当たらない（`display:none`）。
  - **編集は別ページ**：ボタンの並びの最後の行の右端（行に余裕があるとき。無ければ次の行の右端）の「ボタンを編集 →」で、条件ボタンの編集ページ（S2）へ移動する。作成・編集・削除・並べ替えは S2 だけで行う。ホームには［＋］、［×］、ドラッグの取っ手、長押しの動作を置かない。
- **期間**：指定なし／今日／昨日から／前回から。日付の直接指定とN日前からは「詳細条件」で行い（ホームにボタンは置かない）、指定中は注記に「詳細条件で指定中：…」と表示する（どのボタンも押下状態にしない）。「前回から」は履歴が無い初回は「指定なし」扱いで、その旨を注記に表示する。注記は2行分の高さを常に確保し、押しても下の要素が動かないようにする。
- **クエリ表示**：1行固定（折り返さない）。長いときは横にスクロールでき、キーボードでもスクロールできる。警告は横のアイコンに出す。
- **ボタン列**：［X で開く］は最小幅。［⋯］には「Yahoo で開く」「リンクをコピー（X）」「リンクをコピー（Yahoo）」「クエリをコピー」を入れる。
- **お気に入り**：検索エリアとは区切り線で分け、閉じた1行「☆ お気に入り（件数）」で置く。開くと「押して実行」だけの一覧と「お気に入りを編集 →」を出す。初回は閉じ、開閉は localStorage に記憶して次回もその状態で表示する。
- **クエリ表示**：X として出力される検索文字列。高さを固定し（3行まで。長いときは省略）、警告アイコンの場所も常に確保する。警告があるときは件数つきの⚠アイコン。押すと下に警告を展開する（Yahoo で使えない演算子など）。
- **［X で開く］**：新しいタブで開き、履歴に記録する。詳細条件で使った条件は、次回以降のサジェスト検索条件の候補になる（条件ボタンへは自動追加しない）。
- **［☆ 保存］**：保存シート（下からのシート）を開く。名前を入れて「お気に入りに保存」。同じシートで「いつものエゴサに追加：既存を選ぶ／新規作成」もできる。
- **［⋯］**：使用頻度の低い操作を入れた小さなメニュー。「Yahoo で開く」「リンクをコピー（X）」「クエリをコピー」。Esc または外側の操作で閉じる。
- **詳細条件**：開閉エリア。**初期は閉じている**。開くと 3.3 の内容。
  - 開いた一覧は、上位数件を名前・クエリ・［▶ 実行］だけで並べる。編集・複製・削除は S3 で行う。
- **履歴**：ホームには置かない。フッター（2.1.1）に最後の1件を出し、一覧はメニューの履歴ページ（S5）で見る。

### 3.3 詳細条件（個別設定、開閉エリア）
その検索だけの条件。可能な限り細かく指定できる。内容は要件定義書 F3 のとおり。

- セクション（それぞれ折りたたみ可）：語／アカウント／フィルタ／期間／エンジンと表示／条件ボタンの項目別の無効化。
  - **語**：完全一致・通常・表記ゆれ展開（複数の語をORで結ぶ）・除外を、それぞれ複数追加できる。
  - **アカウント**：from／to／メンション／list と、それぞれの除外。
  - **フィルタ**：リプライ、RT、引用、画像、動画、リンク、認証済み、言語、`min_faves`／`min_retweets`／`min_replies`。それぞれ「指定なし／含む／除く」の3択。
  - **期間**：N日前から、日付の直接指定などの細かい指定。「終了日を含む」と表示し、出力時に翌日へ変換する。
  - **エンジンと表示**：X／Yahoo／両方、Xの「最新」タブ。
  - **共通の無効化**：ONの条件ボタンの中身を項目ごとにチェックボックスで並べ、外すとこの検索でだけ無効になる。
- **高度な編集**（タブ）：［構造］と［テキスト］を切り替える。構造は木構造（ノードのON/OFF、削除、並べ替え、グループのAND/OR、生トークン）。テキストは生のクエリ文字列。双方向に同期し、構文エラーは該当箇所に表示して最後に有効だった状態を保つ。
- 設定は即時にクエリ表示とプレビューへ反映する。
- 「この検索をリセット」で個別設定を全部消す（元に戻せるので確認は出さず、トーストに［元に戻す］）。

### 3.4 状態
| 状態 | 表示 |
|---|---|
| 初回（データなし） | 条件ボタンに既定リスト（ホロライブ・にじさんじ）が入っている。お気に入り・履歴は空状態の案内 |
| 条件ボタンが上限 | S2 の［＋ 追加］とサジェストの［＋ 条件ボタンに追加］を無効にし、「上限です」と理由を表示 |
| 参照先が削除済み | 該当のお気に入り・いつものエゴサにアイコンと「復元」への導線 |
| 警告あり | クエリ表示の⚠アイコン |

## 4. メニューのページ（S2〜S7）

共通：ヘッダーに「ホームへ戻る」のパンくずを置く。一覧は空状態（案内と次の操作）を持つ。削除は削除済みへ移し、トーストに［元に戻す］。

### S2：条件ボタンの編集（`/buttons`）
ホームの条件ボタンは押すだけにしたので、**作成・編集・削除・並べ替えはこのページだけ**で行う（表示と編集を分ける）。ホームの「ボタンを編集 →」とメニューから開く。
- 一覧（ドラッグで並べ替え、キーボードでも移動可）。各行：ラベル、中身の要約（等幅）、ON/OFFの初期状態、［編集］［×］。現在の件数／上限（例：12/30）を表示する。
- 一覧の下に**サジェスト検索条件**（直近の検索から。最大20件）を出す。各行：条件（等幅）、［＋ 条件ボタンに追加］。**表示順は変えられない**（取っ手を置かない）。上限のときは追加を無効にして理由を表示する。
- **［＋ 追加］**：M1 を開く。ボタンの作り方は2つ：①ラベルと中身を入力、②**リスト**：URL（`https://x.com/i/lists/<ID>`）またはIDを貼る。ID を取り出して確認を表示する（例：「リスト 1412278227767218179」）。数字以外は受け付けない。
- 既定リスト（F1）から作られたボタンには「既定」の印を付ける。編集・削除はできる。削除後に既定へ戻したいときは「削除済み」から復元するか、［既定のボタンを追加］で再登録する。
- ホームと同じ折りたたみ（2行）は使わず、全件を一覧する。

#### M1：条件ボタンの編集（下からのシート。PC は右側のシート）
- **ラベル**：表示名（必須。20文字まで）。
- **中身**：条件の一覧。1つのボタンに複数の条件を持てる（例：ネタバレ除外 → 語A、語B）。各条件は種類（語・除外・完全一致・アカウント・リスト・フィルタ・生）と値。［＋条件を追加］、各条件の［×］、ドラッグで並べ替え。
- **プレビュー**：中身から生成される文字列（等幅）と、Yahoo で使えない演算子の警告。
- ［保存］／［キャンセル］。参照しているお気に入りの件数を表示し（「3件のお気に入りに反映されます」）、保存すると全部に反映する。
- 空のラベル・空の中身は保存できず、理由をフィールドの下に表示する（モーダルにしない）。

### S3：お気に入り（`/favorites`）
- 一覧（ドラッグで並べ替え）。各行：名前、クエリ、エンジン、最終実行、［▶ 実行］［編集］［複製］［×］。絞り込み入力欄。
- **［×］**：いつものエゴサに使われていなければ、削除済みへ移してトーストに［元に戻す］。**使われているときは確認（M3）**を出す：影響するいつものエゴサをすべて列挙し、「一緒に削除済みへ移します」と案内する。**2件以上なら、さらに再確認**する。OK で、お気に入りと該当のいつものエゴサを同時に削除済みへ移す（トーストの［元に戻す］で全部戻る）。
- ［編集］：名前、検索語、使う条件ボタン、個別設定（S1 の詳細条件と同じ内容）、期間、エンジンを直す。保存先は同じお気に入り（上書きは、ユーザーが明示的に［保存］を押したときだけ）。
- 参照先が削除済みの条件ボタンを使っているものは、⚠アイコンと「条件ボタン『…』が削除済みです［復元］」。

### S4：いつものエゴサ（`/groups`）
- 一覧。各いつものエゴサ：名前、含むお気に入り（並べ替え可）、［▶ 一括実行］、［ブックマークURLを発行（M2）］、［編集］、［×］。「今日は済／未」。
- **追加**：［＋ 追加］（帯の［＋］と同じ）で追加シートを開く。方法は2つ。①**お気に入りをまとめる**：名前を入れ、お気に入りをチェックで選び、開く順を並べる。②**［＋ 条件を指定して新しく作る］**：シート内で検索語・完全一致・条件ボタン・期間を指定し、お気に入りの名前を付けて［お気に入りに保存して追加］。お気に入りができ、チェック済みで一覧に入る（何度でも繰り返せる）。ホームの検索から作るときは S1 の保存シートを使う。
- 中身のお気に入りが削除済みのものには⚠と［削除済みで復元］への導線を出す（実行では飛ばす）。
- 一括実行：クリック起点で全タブを開く。ブロック時は、開けた数／失敗数と、個別リンク一覧を表示する。
- 例：「配信後エゴサ（3個）」＝配信タグ、ファンアートタグ、切り抜きタグ。「今日のエゴサ」＝期間「前回から」を使う。

### S5：履歴（`/history`）
- 新しい順の一覧。各行：日時、検索語、使った条件ボタン、エンジン、実行元。［再実行］［☆ お気に入りに保存］だけ（条件ボタンにする操作は置かない。条件ボタンへはサジェストから追加する）。
- 件数（例：42/100）、［全件削除］（ConfirmDialog）。

### S6：削除済み（`/trash`）
- 種類のタブ：［すべて］［条件ボタン］［お気に入り］［いつものエゴサ］。各タブに件数（例：お気に入り 3/20）を出す。削除した新しい順。各行：種類のバッジ、名前、削除日時、［復元］［中身を見る］［完全に削除］。中身は、条件ボタン＝条件の文字列、お気に入り＝クエリ、いつものエゴサ＝含むお気に入り（削除済みのものに印）。
- **種類ごとに20件**を超えると、その種類の古いものから自動で完全削除される。その旨を上部に常時表示する。
- お気に入りを消したときに連動して消えたいつものエゴサは「お気に入り『…』と一緒に削除」と表示し、［まとめて復元］で一緒に戻せる。
- ［完全に削除］・［この種類をすべて完全削除］・［すべて完全削除］は ConfirmDialog（M3）を挟む。復元は確認なし。
- 復元先が上限に達している場合は、［復元］を無効にして理由を表示する。

### S7：URL解析（`/import`）
- テキスト入力欄にXまたはYahooのURLを貼り付ける。
- 解析結果を、ツリー形式で即時プレビューする。解析できなかった部分は「生トークン」として表示する。
- 対応外のURL（`x.com/search` でも `q` が無い等）には、理由を入力欄の下に表示する。
- ［ホームで編集する］（検索語と詳細条件に展開してホームへ移動）／［新規お気に入りとして保存］。既存のデータは上書きしない。

## 5. S9：ランチャー（`/launch#<データ>`）

### 5.1 目的
ブックマークから開いたとき、設定入りのいつものエゴサを一括で実行する（F8）。

### 5.2 レイアウトと動作
```
┌────────────────────────────────┐
│ いつものエゴサ：配信後エゴサ     │
│ 3件の検索を新しいタブで開きます   │
│                                │
│   [▶ すべて開く]               │
│                                │
│ 1. 配信タグ（X）        [開く] │
│ 2. ファンアート（X）    [開く] │
│ 3. 切り抜き（X）        [開く] │
│ [ホームで開く（新規として保存）] │
└────────────────────────────────┘
```
- ページを開いただけでは自動でタブを開かない。**［すべて開く］のクリックを起点にする**。
- 日付の相対指定は、［すべて開く］の押下時点の日時で計算する。
- 個別の［開く］は、一括で開けなかったときの代替手段として常に表示する。
- ［ホームで開く］は、取り込んだ内容を新規のお気に入り／いつものエゴサとして保存するか確認してから S1 へ移動する。勝手に上書き保存しない。

### 5.3 ポップアップがブロックされた場合
- 開けたタブ数と失敗数を表示する。
- 「ブラウザのポップアップを許可してから、もう一度［すべて開く］を押してください」と案内する。
- 個別リンク一覧から手動で開けるようにする。

### 5.4 エラー状態
| 状態 | 表示 |
|---|---|
| ハッシュが無い／壊れている | 「ブックマークURLを読み込めませんでした」とホームへの導線 |
| 未知のバージョン | 「新しい形式のURLです。アプリを更新してください」 |
| データが大きく、URLが長い | 発行時（M2）に警告済み。読み込めた場合は通常どおり |

## 6. ダイアログ

### M2：ブックマークURL発行（F8）
- いつものエゴサの名前、含むお気に入りの一覧を表示する。
- 生成されたURLを表示し、［コピー］と「ブックマークに追加する手順」の案内を出す。
- URLの長さが警告水準を超えたときは、含めるお気に入りを減らすよう促す（警告水準は定数。要件定義書 F8）。警告はダイアログ内のインライン表示で、別のモーダルは出さない。

### M3：確認ダイアログ
- 完全削除、種類ごと・すべての完全削除、履歴の全件削除、**使われているお気に入りの削除（連動して消えるいつものエゴサの列挙。2件以上は再確認）**だけに使う。［キャンセル］と赤の実行ボタン。Esc で閉じる。

### 6.1 モーダルにしないもの
警告、保存、削除（削除済みへの移動）は、モーダルを使わない。削除はトースト（［元に戻す］付き）、警告はアイコンとインライン表示。

### 6.2 PC（768px以上）の配置
スマホの配置を基準に、広い画面では次のようにする。
- **ホーム**：スマホと同じ1カラム（タイル型にしない）。幅は最大 672px で中央に寄せる。条件ボタンの折りたたみは、スマホと同じ2行。帯のいつものエゴサは、幅に余裕があるぶん名前を長く表示する。
- **左メニュー**：768px〜1279px はスマホと同じ開閉（最大 360px）。1280px 以上は常時表示のサイドバー。
- **メニューのページ**：一覧は2カラム（一覧＋編集シート）。M1 は右側のシート。
- **コマンドパレット**：中央に表示。幅は最大 480px。
- キーボードショートカット：Ctrl/⌘+K でパレット、Esc で閉じる。

## 7. アクセシビリティ・表示方針
- すべての操作をキーボードで行えるようにする（メニューは Tab／Esc、並べ替えは Space＋矢印、ダイアログは Esc で閉じる）。
- 色だけで状態を示さない（条件ボタンは ON が ✓＋塗りつぶし、OFF が ○＋枠線で、`aria-pressed` も付ける。警告はアイコンと文言を併用）。
- **UIの文言は日本語と英語の両方に対応する（MVP の必須要件）。** 初期値はブラウザの言語（日本語以外は英語）、メニューの下部の言語切替で切り替えられる（設定画面は置かない）。文言は画面のコードに直書きせず、言語ごとの辞書から出す。長さが変わっても崩れないよう、帯の名前の省略、条件ボタンの幅固定、フッターの1行表示を、どちらの言語でも確かめる。クエリ文字列は等幅フォントで表示する。実装は GitHub の Issue で管理する。モックは日本語のみ。
- 最小対応幅は 360px。768px 未満は1カラム。
- 折りたたみで隠した要素は、フォーカスが当たらないようにする（`inert`）。
- 件数の上限値は画面の文言に直書きせず、定数から出す。

## 8. 画面遷移
- ホーム ⇄ 各メニューのページ：左メニュー（［≡］またはサイドバー）で移動する。コマンドパレットからも移動できる。
- ホーム → いつものエゴサの帯の［＋］→ 追加シート（どのページでも開く）。
- ホーム →「ボタンを編集 →」→ S2（条件ボタンの編集。M1 のシートはここで開く）。ホーム →「お気に入りを編集 →」→ S3。いつものエゴサの帯のボタン→実行（画面は移動しない）、フッターの［履歴 →］→ S5。
- S4 → M2（発行）：ダイアログで開く。
- ブックマーク → S9 →（［ホームで開く］）→ S1。
- 履歴／お気に入り → ［再実行／実行］→ 新しいタブ（画面は移動しない）。
