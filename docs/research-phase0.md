# Phase 0 調査結果（要件定義書 8章の確認）

調査日：2026-11-15。方法はWeb検索と公式ヘルプの取得のみ。**実際のX／Yahooの画面で動作を確かめたものではない**。
確度の凡例：【公式】公式ドキュメントで確認／【実測】実ページのHTMLで確認／【二次】第三者の記事のみ／【未確認】根拠なし。

## 1. Yahoo!リアルタイム検索のURL形式
- ベース：`https://search.yahoo.co.jp/realtime/search?p=<キーワード>` 【実測】
- `p`：検索キーワード（URLエンコード。`#兎田ぺこら` のようなハッシュタグも `p` に入る）【実測】
- `ei=UTF-8`：文字コード【実測】
- `mtype=image`：「画像・動画」フィルター【実測】
- 並べ替え（新着順／ベストポスト）はURLパラメータに見当たらない【実測】。画面上の切替のみの可能性が高い。
- `rkf`、`ifr`、`utm_*` は内部・計測用。生成するURLには付けない。
- 期間指定：取得したページに期間フィルターは無い【実測】。古い記事（2016年）には `lts`／`uts`（UNIX時間）の例があるが、現在も有効かは**未確認**【二次】。

## 2. Yahooで使える演算子【公式：サポートページ H000011629】
| 機能 | 構文 | 備考 |
|---|---|---|
| OR | `(A B)` | **括弧の中を半角スペースで区切る。`OR` という語ではない** |
| 除外 | `A -B` | |
| アカウントの投稿 | `ID:xxxx`（`id:` も可） | `ID:xxxx 語` で絞り込める |
| アカウント宛て | `@xxxx` | |
| ハッシュタグ | `#yyyy` | 半角のみ |
| URL・ドメイン | `URL:...` | |

- 記号はすべて半角。
- 公式ページに記載が**無い**もの：引用符による完全一致、`since:`／`until:`、`list:`、`filter:`、`from:`／`to:`、複数演算子の組み合わせ規則。
- `-ID:`（アカウントの除外）は公式記載が無く、試した人は除外されなかったと報告している【二次】。アカウントを隠すにはYahooのミュート機能を使う（ログイン時50件、未ログイン時10件）【二次】。

## 3. Xの演算子
- `until:` は**その日を含まない**（終了日を含めたければ翌日を指定）【二次、複数の記事が一致】。日付はUTCで評価される【二次】。
- 時刻単位：`since_time:`／`until_time:`（UNIX秒）という演算子の記述がある【二次】。「画面によっては使えない」とする記述もあり、**動作は未確認**。
- `list:`、`filter:replies`、`since:`、`until:`、`min_faves:`、`lang:` の存在は複数の記事で一致【二次】。
- `list:` と `to:`／`from:` の併用：**根拠となる情報が見つからなかった**【未確認】。
- クエリ長：公式ドキュメントの数値は X **API** のもの（Recent search 512文字、Full-archive 1,024文字）【公式】。**Web検索画面の上限は不明**【未確認】。
- XのヘルプページはHTTP 403で取得できなかった。Xの画面での確認は、ログインが必要なため今回できていない。

## 4. 要件への影響（要件定義書の修正案。承認後に反映）
| # | 影響 | 修正案 |
|---|---|---|
| 1 | YahooのORは `(A B)` | URL生成のYahoo変換で、ORグループを `(A B)` に変換する。Xとは構文が違うため、変換器を分ける |
| 2 | Yahooに完全一致の記載が無い | 引用符付きの語をそのまま出力するが、「完全一致として動作しない可能性」を警告に出す |
| 3 | Yahooに期間指定が無い | `since:`／`until:`は出力しない。期間を指定した検索には「Yahooでは期間指定が使えません」と警告する。F2の「日付の自動入力」はXにのみ適用する |
| 4 | Yahooに `list:`／`to:`／`from:`／`filter:` が無い | 警告を出して除外する。`from:` は `ID:`、`to:` は `@` に変換できる。この対応はテストで固定する |
| 5 | Yahooの `-ID:` が効かない | アカウント除外は警告し、ミュート機能を案内する |
| 6 | `until:` は日付を含まない | 「期間の終了日」を画面では「含む」と表示し、出力時に翌日へ変換する。UTC基準である旨を表示する |
| 7 | 時刻指定・`list:`併用・Web上限が未確認 | 実機で確認するまで「実験的」として扱う。生トークンとして保持するので往復は壊れない |
